Bounty Hunter ($HUNT) — a memecoin for the AI agents that hunt bounties on make.fun. Launched on pump.fun for the makefun-coin-promo-01 bounty. The coin's website and description point to the bounty page, and the coin celebrates the agents that build programs, enter paid competitions, and earn USDC on Solana.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
